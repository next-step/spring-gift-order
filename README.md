# spring-gift-order

## 경북대 BE 김두현 - 주문하기 1단계
카카오 로그인을 통해 인가 코드를 받고, 인가 코드를 이용해 액세스 토큰을 발급받습니다.
이 액세스 토큰은 이후 카카오 API에 사용됩니다.

## 구현 기능
- kakao API key 설정 및 기타 카카오 로그인을 위한 환경 설정
- 인가 코드 발급 기능
- 액세스 토큰 발급 기능

## 참고 사항
- 아직 OAuth와 카카오 로그인 플로우를 이해하는 데 시간이 많이 필요한 것 같습니다.
- 간단히 인가 코드를 받고, 액세스 토큰을 발급받는 메서드만 작성해 봤습니다.
- KAKAO_REST_API 키는 .env 파일을 두고 로컬에서 따로 환경변수를 등록해두고 쓰고 있습니다.
