# spring-gift-order

## 경북대 BE 김두현 - 주문하기 3단계
지금까지 만든 선물하기 서비스를 배포합니다.
지속적인 배포를 위한 배포 스크립트를 작성합니다.

## 구현 기능
- 배포를 위한 deploy.sh 스크립트 작성
- AWS EC2 인스턴스 생성 및 연결

## 참고 사항
- 처음으로 해 보는 배포라서 과제 힌트를 많이 참고해서 스크립트를 작성했습니다.
- 배포 확인 작업에서 카카오 로그인 기능이 자꾸 안 돼서 카카오 앱의 주소와 리다이렉트 주소를 수정했습니다. 배포 주소로만 요청이 가능합니다.
- intellij에서 애플리케이션 빌드, jar 파일을 서버로 전송, 서버 접속 후 deploy.sh 실행 순서로 진행했습니다. 제가 올바른 방식으로 수행한 건지 잘 모르겠습니다.
- 코드 작성부터 배포까지 AI의 도움을 많이 받았습니다.
