# spring-gift-order

## 경북대 BE 김두현 - 주문하기 2단계
카카오톡 메세지 API를 이용해 주문하기 기능을 구현했습니다.
주문할 때 request dto에 메세지를 작성하고, 상품 옵션과 수량을 선택하면 해당 정보가 나에게 메세지로 보내지고,
상품 옵션의 재고가 차감되며 위시리스트에서 해당 상품이 삭제됩니다.

## 구현 기능
- 주문 API 구현: 주문 요청을 받아 처리하는 엔드포인트를 구현했습니다.
- 주문 시에 상품 옵션 재고 차감 기능 구현
- 주문 시에 위시리스트 해당 상품 삭제 기능 구현
- 카카오 메세지 API 연동

## 참고 사항
- /login 경로로 로그인 시에 받은 JWT 토큰값을 Authorization 헤더에 넣고,
- /kakao/login 경로에서 카카오 로그인 시 받은 액세스 토큰 값을 kakao-access-token 헤더에 넣은 상태로 주문 요청을 해야 합니다.
- 로그인 시에 받은 JWT 토큰으로부터 memberId를 받아서 본인의 위시리스트 삭제 기능을 수행합니다.
- 완벽히 숙지되지 않은 상태에서 구현하려다 보니 정말 요구사항에 나온 기본적인 기능들만 구현해 봤습니다.
- 예외처리 및 테스트 코드 작성은 천천히 추가해야 할 것 같습니다.
