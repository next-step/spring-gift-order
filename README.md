## Step 2

애플리케이션 작동 구조
로그인 : 카카오 로그인 -> 카카오 엑세스 토큰 발행 -> 엑세스 토큰을 통한 JWT 토큰 발행
- SocialUser 엔티티 구성
  - 문제점  
    - 주문을 하려면 일단, JWT 토큰을 이용해서 사용자를 받습니다. 그런데 카카오톡 메시지를 보내기 위해서는 다시 카카오 엑세스 토큰이 필요합니다. 이를 위해 JWT -> 엑세스 토큰 같은건 없나 라고 찾아봤지만 없었습니다,,, 그래서 어쩔수없이 엔티티를 따로 또 설정해서, 엑세스 토큰을 저장했는데, 저는 이 구조가 보안상도 그렇고, 토큰 특성상 많이 변경될텐데, 이 구조는 별로 효율적이지 않다고 생각합니다.


- Order : 주문 생성 및 주문 내역 반환
  - 이 부분은 Order 엔티티를 정의해서, 그 안에 Option, User, Item 등을 포함하도록 설정했습니다.
