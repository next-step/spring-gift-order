# spring-gift-order

## step 0 기본 코드 준비
- 기존 코드를 gift-order 저장소로 이관

## Step 1. 카카오 로그인

카카오 로그인을 통해 인가 코드를 받고, 인가 코드를 사용해 토큰을 받은 후 향후 카카오 API 사용을 준비한다.

- 카카오계정 로그인을 통해 인증 코드를 받기
- 토큰 받기를 읽고 액세스 토큰을 추출
- 앱 키, 인가 코드가 절대 유출되지 않도록 한다.
    - 특히 시크릿 키는 GitHub나 클라이언트 코드 등 외부에서 볼 수 있는 곳에 추가하지 않는다.

## Step 2. 주문 하기 
1. 주문 생성 기능

    상품 옵션 ID와 수량을 받아 주문을 생성한다.
    
    사용자가 전달한 메시지를 함께 저장한다.
    
    주문 시 해당 옵션의 재고 수량을 차감한다.
    
    주문 정보에 주문 시각(orderDateTime)을 기록한다.

2. 위시리스트 연동

    주문한 상품이 위시리스트에 있을 경우, 위시리스트에서 해당 상품을 제거한다.

3. 카카오톡 메시지 전송

    주문이 완료되면 "나에게 보내기"를 통해 카카오톡으로 주문 내역 메시지를 전송한다.
    
    메시지는 기본 템플릿 또는 사용자 정의 템플릿으로 작성할 수 있도록 구성한다.

## Step 3. 주문 하기 
1. 배포 스크립트 작성
    - 기존에 빌드된 JAR 파일을 자동으로 서버에 배포하고 실행하는 `deploy.sh` 작성
    - 이전 실행 중인 애플리케이션 프로세스를 안전하게 종료 후 재배포
    - 로그를 파일로 남기지 않고 무시하는 방식으로 백그라운드 실행 설정
2. CORS 설정
    - 클라이언트와 다른 Origin 간 통신을 허용하도록 서버에 CORS 설정 추가
    - `GET`, `POST`, `PATCH`, `DELETE` 요청 허용
