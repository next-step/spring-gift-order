# spring-gift-order

## 기능 목록

### 1. 주문 관리 기능

-   [ ] 주문 도메인 모델 구현 (Order)
-   [ ] 주문 요청/응답 DTO 구현 (OrderRequest, OrderResponse)
-   [ ] 주문 리포지토리 구현 (OrderRepository)
-   [ ] 주문 서비스 구현 (OrderService)
-   [ ] 주문 컨트롤러 구현 (OrderController)

### 2. 주문 비즈니스 로직

-   [ ] 상품 옵션과 수량을 선택하여 주문 생성
-   [ ] 주문 시 상품 옵션 수량 차감
-   [ ] 위시리스트에 있는 상품 주문 시 위시리스트에서 삭제
-   [ ] 주문 내역 조회 기능

### 3. 카카오톡 메시지 전송 기능

-   [ ] 카카오톡 메시지 API 연동을 위한 설정
-   [ ] 카카오톡 메시지 전송 서비스 구현
-   [ ] 주문 완료 시 카카오톡 메시지 자동 전송
-   [ ] 메시지 템플릿 구현 (주문 내역 포함)

### 4. 인증 및 보안

-   [ ] JWT 토큰 기반 인증 구현
-   [ ] 로그인한 사용자만 주문 가능하도록 권한 체크
-   [ ] 카카오 로그인 연동 완성

### 5. API 엔드포인트

-   [ ] POST /api/orders - 주문 생성
-   [ ] GET /api/orders - 주문 내역 조회
-   [ ] 적절한 HTTP 상태 코드 및 응답 형식 구현
